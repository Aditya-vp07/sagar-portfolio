# Sagar Hugar portfolio

Fully static portfolio for Sagar Hugar. All content is Sagar Hugar's, drawn from his own site and public résumé.

The page data lives in `assets/js/data.js` and is served through a small local shim that emulates a content API, so the site runs anywhere static: GitHub Pages, Netlify, Vercel. No backend needed.

Note: the Brunswick Grotesque font file is a licensed commercial typeface. Replace it with a purchased license or a similar free face (e.g. Inter, Schibsted Grotesk) before serious production use.
