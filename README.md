# Sagar Hugar portfolio

Static portfolio for Sagar Hugar, replicating the design of Andrew Trousdale's site (https://andrewtrousdale.com). Layout, styles and interaction engine are adapted from that site; all content belongs to Sagar Hugar (from https://sagarhugar.com and his public résumé).

Fully static: the Kirby CMS API the original design depends on is emulated locally in `assets/js/data.js`, so it can be hosted anywhere (GitHub Pages, Netlify, Vercel) with no backend.

Note: the Brunswick Grotesque font was taken from the original site. It is a licensed commercial typeface, so replace it with a purchased license or a similar free face (e.g. Inter, Schibsted Grotesk) before serious production use.
